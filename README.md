## 💡 为什么选择 Emoji-Studio？

在微信表情开放平台（[sticker.weixin.qq.com](https://sticker.weixin.qq.com)）上传表情包时，创作者通常面临以下繁琐痛点：
1. **尺寸与体积死线苛刻**：主图必须是严格 240×240 GIF 且体积严格 $\le 500\text{KB}$，添加描边艺术字后体积极易暴涨超标；
2. **原画带字修改困难**：AI 生成的动态原画左侧、右侧或顶部常带有变形错别字或杂乱文字，手动 PS 逐帧修图极其耗时；
3. **文字排版自由度低**：很多工具只支持顶部横排，无法在角色左侧/右侧排布竖排中文字体；
4. **伴生物料繁多复杂**：横幅（750×400）、封面（240×240 透明底）、图标（50×50 透明底）、赞赏图等规格各有严格要求；
5. **重复排版耗时费力**：一张图调好的艺术字，要在 15 张图上机械重复调整 15 遍；
6. **提审填表繁琐痛苦**：每次提审要在网页上手动填写专辑名称、介绍、赞赏引导语以及 15 个表情含义。

**Emoji-Studio 将上述全流程全部自动化，从一段 AI 生成的 16:9 视频到最终提审过审，仅需几分钟！**

## ✨ 核心特性

### 1. 📹 AI 视频 15 宫格无缝切片
- 自动解析 5×3 宫格 16:9 动态视频（支持可灵、海螺、Runway、Sora 等生成的网格视频）。
- 精准按行列边界秒级切片生成 15 张标准的 240×240 GIF 动态图。
- 内置 **16:9 防裁剪安全底图垫底** 与 **安全内缩（94%）** 算法，防止角色头顶和脚部在生成视频时被边缘吞没。

### 2. 🪄 泛洪漫水算法智能透明底
- 采用连通域漫水算法（Flood-Fill Alpha Matte），智能识别背景边缘并精准镂空。
- 针对复杂边缘进行柔化与透明通道保护，保留生动动态细节的同时杜绝纯黑或纯白底色瑕疵。

### 3. ✏️ 表情文字工坊（横排/竖排与全方位旧字抹除）
- **📜 竖排 / 📝 横排自由排版**：
  - 支持传统自左至右横向排版，以及**自上而下逐字排列的竖排文字**；
  - 针对角色左右空白区域，提供【👈 左侧竖排】与【👉 右侧竖排】一键定位预设；
  - 具备 **水平 X 轴滑块** 与 **垂直 Y 轴滑块** 双轴像素级精细微调。
- **🛡️ 全方位智能旧字抹除（支持左侧 / 右侧 / 顶部 / 底部）**：
  - 原画自带变形字或错别字时，可一键启用局部透明度抹除；
  - 内置 4 大一键预设胶囊：**【👈 左侧抹除 (65×240)】**、**【👉 右侧抹除 (65×240)】**、**【⬆ 顶部抹除 (240×40)】**、**【⬇ 底部抹除 (240×40)】**；
  - 配备 **起始 X、抹除宽度、起始 Y、抹除高度** 4 轴自由调整滑块；
  - 240×240 视口提供**红色高亮虚线框与实时尺寸标注**（如 `抹除 65×240`），所见即所得，精准保护人物原画主体。
- **🛡️ 100% 开源免费商用中文字库**：
  - 默认搭载与支持 OPPO Sans Heavy（特粗黑体）、华为鸿蒙黑体、阿里巴巴普惠体、思源黑体/宋体，提审零版权争议风险；
  - 支持一键导入本地任意 `.ttf`/`.otf` 字体文件。
- **🎨 高对比艺术字色彩与多级描边**：
  - 精选喜庆大红、经典黑、纯白、富贵金、微信绿等 10 款所见即所得实体色卡及自定义拾色器；
  - 0~8px 描边粗细与高对比描边颜色配置，无论浅色还是深色聊天背景均清晰醒目。
- **🌟 一键批量同步排版规范**：
  - 只需在第 1 张图调好满意的排版方向、字号、色彩、描边与抹除区域，点击【一键为全部表情添加文字】，秒级将规范批量应用到全部 15 张表情！
- **📋 批量标题核对与粘贴**：
  - 提供专属弹窗，支持多行批量粘贴或一次性核对编辑全部 15 张表情的标题文案。

### 4. 🗜️ 高保真自适应极限控容压缩（严格 ≤480KB）
- **多通调色板（PaletteGen）**：针对艺术字描边边缘的抗锯齿杂色，自动启用 8 级调色板限色梯度搜索（80/64/48/32/24色 + 有序 Bayer 抖动）。
- **智能降频与隔帧抽样兜底（Step-2 Decimation）**：在肉眼几乎无损的情况下将文件体积缩减 **35% ~ 50%+**，100% 压制在微信官方安全红线（≤480KB）之内。
- **全局一键压缩、多选定向压缩与单卡片极速压制**：随时对工程内动图执行体积压制，并带有直观的 🟢/🔴 红绿合规体积指示徽章。

### 5. 🚀 自选目标目录 • 一键打包微信提审全套物料包
- 一键自动生成微信开放平台所需的全部 8 项物料：
  - `01_表情主图_240x240_GIF/` (15 个合规 GIF 主图)
  - `02_详情页横幅_750x400.png` (≤80KB 自动压制)
  - `03_表情封面图_240x240.png` (透明底，≤100KB)
  - `04_聊天页图标_50x50.png` (透明底，≤30KB)
  - `05_赞赏引导图_750x560.png` (≤100KB)
  - `06_赞赏致谢图_750x750.png` (≤200KB)
  - `微信后台_F12一键填表脚本.js`
  - `微信提审文案与操作指南.txt`
- **自选目标文件夹与智能路径记忆（PathMemory）**：可自由选择导出目录（如桌面、交付文件夹等），上传/下载/导出均会自动记住上次选择的路径。

### 6. ⚡ 微信后台 F12 一键全自动秒级填表
- 自动生成专属 JavaScript 填表代码。
- 在微信表情审核页面按 `F12` 打开控制台（Console），粘贴回车：
  - **表情专辑名称、专辑介绍、赞赏引导语、15 个表情含义全部秒级填满，并自动勾选原创声明！**

## 🛠️ 环境准备与快速上手

### 1. 克隆代码仓库
```bash
git clone https://github.com/weklyy/Emoji-Studio.git
cd Emoji-Studio
```

### 2. 安装 Python 依赖
推荐使用 Python 3.9 及以上版本：
```bash
pip install -r requirements.txt
```

### 3. 安装 FFmpeg
本项目使用 FFmpeg 进行视频切片与高质量 GIF 编解码，请确保 `ffmpeg` 已安装并加入系统环境变量 `PATH`：
- **Windows (通过 Scoop 或 Chocolatey)**:
  ```powershell
  scoop install ffmpeg
  # 或者
  choco install ffmpeg
  ```
- **macOS (通过 Homebrew)**:
  ```bash
  brew install ffmpeg
  ```
- 也可直接从 [FFmpeg 官方网站](https://ffmpeg.org/download.html) 下载并将可执行文件解压至系统目录。

### 4. 启动软件
- **Windows 用户**：直接双击运行根目录下的 `启动Emoji-Studio.bat` 或 `启动微信表情工坊.bat`
- **命令行启动**：
  ```bash
  python WeChatEmojiStudio/main.py
  ```

## 📖 微信表情包极速提审实战指南

1. **准备素材**：在左侧新建工程，在步骤 2 生成 16:9 防裁剪安全图，送入 AI 视频工具生成 15 宫格视频；
2. **一键切片**：在步骤 3 选择导出的视频，点击 **【⚡ 一键切片为 15 个 GIF】**；
3. **文字排版与修字**：
   - 点击任意卡片或点击 **【✏️ 手动添加与排版文字】** 打开文字工坊；
   - **旧字抹除**：若原图左侧/右侧有错别字，点击【👈 左侧抹除】或【👉 右侧抹除】将其透明化；
   - **文字排版**：选择【📜 竖向排版】或【📝 横向排版】，设置字号、颜色与描边；
   - **一键同步**：点击 **【🌟 一键为全部表情添加文字】**，秒级为全部 15 张表情自动统一排版；
4. **体积校验**：右侧卡片若有超标（🔴 警示），点击卡片底部的 **【🗜️】** 或点击工作台的 **【一键批量压缩】**，全量控制至安全线（≤480KB）；
5. **一键打包**：点击右下角 **【🚀 一键打包微信提审全套物料包】**，自由选择目标保存文件夹（系统会自动记住该路径）；
6. **提审填表**：登录微信表情开放平台，按生成的规范文件夹上传物料，点击软件中的 **【⚡ 一键复制 F12 自动填表脚本】**，在浏览器控制台（Console）粘贴回车，瞬间完成提审！
